# Bypen PC program

The Windows program for Bypen, the Android app that turns a tablet and its S Pen on a USB cable into a pen pad for
drawing apps on your Windows PC (pressure, tilt, eraser and hover, as a Windows Ink pen; no driver).

- Download: `Bypen-PC.zip` under [Releases](https://github.com/promm-1i/bypen/releases/latest)
- Setup guide: https://noveriq.co.kr/bypen/en/ (한국어: https://noveriq.co.kr/bypen/)
- Tablet app: Google Play, "Bypen"

Windows 10 or Windows 11, 64-bit. Unzip and run `bypen-host.exe`; it sits in the notification area. Keep the unzipped
folder: it holds the virtual display driver files.
If "Windows protected your PC" appears, choose More info → Run anyway.

Only the program files are published here, not the source code.
